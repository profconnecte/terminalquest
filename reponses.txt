Défi	Commande(s)
Plusieurs commandes : les saisir séparément, dans l'ordre indiqué par →. Les PID correspondent au parcours standard ; utiliser ceux affichés par le terminal si nécessaire.

1 · Se repérer	pwd
2 · Explorer le serveur	ls
3 · Lire le mode d’emploi	man ls
4 · Un chemin relatif	cd tournoi/
5 · Les fichiers cachés	ls -a
6 · Lire le message secret	cat .staff.txt
7 · Identifier le propriétaire	ls -l briefing.txt
8 · Combiner des options	ls -la
9 · Un briefing numéroté	cat -n briefing.txt
10 · Revenir au parent	cd ..
11 · Depuis la racine	cd /home/etudiant/tournoi/
12 · Installer la régie	mkdir finale
13 · Créer une arborescence	mkdir -p finale/assets/images
14 · Deux fichiers à préparer	touch finale/annonce.txt finale/journal.txt
15 · Une annonce à l’écran	echo "Finale a 20h"
16 · Enregistrer l’annonce	echo "Finale a 20h" > finale/annonce.txt
17 · Ajouter sans effacer	echo "Aurora vs Pulse" >> finale/annonce.txt
18 · Actualiser sans effacer	touch finale/annonce.txt
19 · Contrôler la livraison	cat finale/annonce.txt finale/journal.txt
20 · Au cœur de la régie	cd finale/
21 · Copier ici	cp ../equipes.txt .
22 · Copier vers le parent	cp journal.txt ..
23 · Copier vers un autre dossier	cp annonce.txt assets/
24 · Copier par chemins absolus	cp /home/etudiant/tournoi/briefing.txt /home/etudiant/tournoi/finale/briefing-regie.txt
25 · Sauvegarder un dossier	cp -r assets/ backup
26 · Renommer le lineup	mv equipes.txt lineup.txt
27 · Déplacer vers le parent	mv briefing-regie.txt ..
28 · Récupérer ici	mv ../briefing-regie.txt .
29 · Changer de dossier et de nom	mv briefing-regie.txt assets/briefing.txt
30 · Déplacer par chemins absolus	mv /home/etudiant/tournoi/journal.txt /home/etudiant/tournoi/finale/assets/journal-archive.txt
31 · Écrire sans saut de ligne	echo -n DIRECT > journal.txt
32 · Ne pas créer par accident	touch -c absent.txt
33 · Retirer le brouillon	rm ../brouillon.txt
34 · Supprimer un dossier vide	rm -d assets/images/
35 · Nettoyer une sauvegarde	rm -r backup/
36 · Dernier contrôle	ls -la /home/etudiant/tournoi/finale/
37 · Vérifier l’identité de la régie	whoami → id
38 · Vérifier la protection des comptes	cat /etc/shadow (Résultat attendu : permission non accordée.)
39 · Contrôler les autorisations de la régie	sudo -l
40 · Identifier le compte système	id root
41 · Créer le compte vidéo	sudo adduser alice → id alice
42 · Lire la fiche du compte	cat /etc/passwd (ou grep "alice" /etc/passwd, grep "alice:" /etc/passwd, grep "^alice:" /etc/passwd)
43 · Vérifier le mot de passe de test	sudo adduser bob → sudo passwd bob → sudo cat /etc/shadow (ou sudo grep "bob" /etc/shadow, sudo grep "bob:" /etc/shadow, sudo grep "^bob:" /etc/shadow)
44 · Créer le groupe de la régie	sudo groupadd regie → getent group regie
45 · Rattacher la cadreuse à la régie	sudo usermod -aG regie alice → id alice
46 · Attribuer le dossier des équipements	sudo mkdir /srv/regie → sudo chown root:regie /srv/regie → ls -ld /srv/regie
47 · Réserver le dossier à la régie	sudo chmod 770 /srv/regie
48 · Tester l’accès d’Alice	sudo -u alice touch /srv/regie/test-video.txt
49 · Tester le refus hors du groupe	sudo -u nobody touch /srv/regie/test-externe.txt (Résultat attendu : permission non accordée.)
50 · Inventorier les processus	ps aux
51 · Lancer un essai en arrière-plan	sleep 90 &
52 · Terminer le processus de répétition	pgrep -x sleep → kill 2401
53 · Vérifier l’accès distant	systemctl status ssh
54 · Préparer le service d’export	sudo systemctl start nexus-export → sudo systemctl enable nexus-export
55 · Lire les derniers événements	journalctl -n 6
56 · Filtrer le journal du direct	journalctl -b -u nexus-export
57 · Préparer l’espace de support	sudo adduser technicien1 → sudo adduser technicien2 → sudo groupadd support → sudo usermod -aG support technicien1 → sudo usermod -aG support technicien2 → sudo mkdir /srv/support → sudo chown root:support /srv/support → sudo chmod 2770 /srv/support → ls -ld /srv/support → sudo -u technicien1 touch /srv/support/test.txt → sudo -u technicien1 chmod g+w /srv/support/test.txt → sudo -u technicien2 touch /srv/support/test.txt → sudo -u nobody ls /srv/support (La dernière commande doit signaler un refus d’accès.)
58 · Repérer les dossiers personnels	ls /home
59 · Repérer la configuration système	ls /etc
60 · Vérifier sa session de régie	whoami → pwd
61 · Préparer les dossiers des replays	mkdir -p replays/bruts replays/valides exports
62 · Rejoindre les exports	cd replays/bruts → cd ../../exports
63 · Vérifier le début des essais	head -n 8 /var/log/nexus/stream.log
64 · Examiner les dernières entrées	tail -n 12 /var/log/nexus/stream.log
65 · Repérer les pertes de signal	grep "signal perdu" /var/log/nexus/stream.log
66 · Lancer le test de secours	sleep 45 &
67 · Localiser le test de secours	pgrep -x sleep
68 · Arrêter le test de secours	kill 2402
69 · Relancer les exports	sudo systemctl restart nexus-export
70 · Diagnostiquer la panne d’archivage	systemctl status nexus-archive → journalctl -u nexus-archive (Le service est en échec. Le journal indique que /var/lib/nexus/archives est introuvable.)
